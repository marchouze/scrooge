Seeds

The visibility index for every foundational build-phase seed. Seeds come in two forms: boot ingesters (market-data reference fixtures loaded into the market-data store on every server boot) and standing scripts (idempotent scripts/*.ts that append foundational events — party register, security master, models, RAS limits, KYC, policy, capital). Each card shows its source file, how it runs, and live counts of the events / market-data ticks it has produced. A seed may not ship invisibly (Trusted-Figures Program, D-TRUSTED-FIGURES-PROGRAM-V1).
