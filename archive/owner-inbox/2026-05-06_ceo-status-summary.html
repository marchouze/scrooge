The six architectural principles (post-consolidation)

From CLAUDE.md. These bind every team member and every deliverable. Old P6 + P7 consolidated into the new P6 on 2026-05-06; Principle 2 (atomic citation) retained separately.

  1. Events are the only source of truth. Balances, capital, ratios, regulatory cells — all queries over the event log; as-of replay first-class.
  2. Every action traces to a source (atomic citation discipline). No control or process without a register-linked citation.
  3. Cloud-native; nothing manual or physical except where essential. Infrastructure as code; coded workflows; structured documents; ECTA wet-signatures only where statute requires.
  4. Security designed in from the start. Threat modelling per design, zero trust, HSM-backed keys, secure SDLC, immutable audit; aligned with Joint Standard 1 of 2024.
  5. Multi-currency, multi-entity, multi-country from day one. Single-currency / single-entity / single-jurisdiction shortcuts forbidden; new entities and currencies are configuration, not project work.
  6. Single-graph discipline. Downward: presentations derive from data — Data → Process → Standard → Policy → Presentation; generated, not authored. Upward: capabilities justify through procedure to regulation — Reg → Policy → Procedure → System Capability; no orphan functionality, no orphan procedures, every procedure mandate-owned. Architectural integrity check (Principle 6 — upward chain)

The chain Reg → Policy → Procedure → System Capability remains wired bidirectionally:

Forward: Reg → Capability

  • Reg → Policy: obligations register maps 178 obligations
  • Policy → Procedure: procedures index links every approved policy
  • Procedure → Capability: each populated procedure names its @platform/... components; today's additions (projections, identity) now available
  • Mandate ownership: every procedure has an owner whose persona file covers the substance

Backward: Capability → Reg

  • Given a capability, find every procedure that names it
  • Given a procedure, find its source policy
  • Given a policy, find every ORG-* obligation it discharges
  • Given an ORG-*, find the regulator instrument under /Regulations/<regulator>/
  • Vera tests this end-to-end as continuous-controls evidence
