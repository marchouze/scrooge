SLA Rule Approvals

Four-eyes governance gate for the rules-as-data sub-ledger accounting (SLA) engine. A rule/version is interpreter-eligible only after an attested SlaRuleApproved whose approver ≠ publisher. The events are canonical; this page is a render plus an action that emits the attested event. No per-posting approval exists (Principle 6 — the gate is on the rule, not the booking).

Production stays IFRS-only. SARB-BA-RETURN rules are published/dry-run only and are NOT activated; activation is the separate CFO + CoSec joint-approval round. In-force IFRS rules carry a build-phase grandfather approval so production posting is unchanged.
