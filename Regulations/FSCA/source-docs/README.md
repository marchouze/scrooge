## Retrieval notes

- The FSCA website (fsca.co.za) returns 404 for most legislation document paths and requires
  authentication for the legislation section. The faisombud.co.za site hosted the GCC PDF publicly.
- The FAIS Act original gazette version was retrieved from gov.za.
- The Determination of Fit and Proper Requirements 2017 (BN 194 of 2017) and the Conflict of
  Interest Code (BN 58 of 2010) are not publicly accessible via automated fetch. Manual download
  from the FSCA regulated-entities/FSP section is required.
- For the consolidated FAIS Act (updated to 1 April 2023), see SAFLII:
  https://www.saflii.org/za/legis/consol_act/faaisa2002423/ (Cloudflare-protected; browser required)
